# POLAR OS Microvideo Visual Identity

## Style Prompt
A dark technical command interface with cinematic restraint: near-black canvas, white/silver P.O.L.A.R. character, electric cyan system energy, red polarity energy, fine grid lines, scanning sweeps, compact module codes, and fast deterministic reveals. The result should feel like entering an operating-system module, never a generic loading screen.

## Colors
- Void Black: #020409
- Electric Cyan: #00E5FF
- Polarity Red: #FF264A
- Signal White: #EFF8FF
- Molten Gold: #FFB300

## Typography
- DejaVu Sans / Montserrat-style geometric sans
- Bold uppercase for module names
- Compact technical sans for system codes and captions

## Motion
- 0.6–1.2 second module cards
- Red and cyan energy cross-screen wipes
- Scanning line and quickly completing progress rail
- P.O.L.A.R. enters with a subtle scale and horizontal reveal
- No infinite loops; no generic spinner

## What NOT to Do
- No plain page-load spinner
- No long unskippable intro
- No random glitch spam
- No low-contrast captions
- No forced sound before user interaction
